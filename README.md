I build maintainable, high-throughput software systems with an emphasis on clean domain separation, robust database design, and resilient APIs. My work ranges from enterprise ERP engines and B2B platforms to cloud management utilities and automation pipelines.

  Built native desktop and command-line utilities for Linux environments, including secure AWS profile management and credential orchestration tools.

---

### Engineering Principles

1. **Explicit Over Implicit:** Prefer well-typed contracts, deterministic error handling, and clear schema constraints over magic configurations.
2. **Domain Isolation:** Package-by-feature design so modules can be added, tested, or scaled independently without cascading failures.
3. **Performance at the Data Layer:** Indexing, batch querying, and connection pooling take precedence over patchy application-level caching.
